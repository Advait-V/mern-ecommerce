# MERN E-Commerce Website

A full-stack e-commerce application built using the MERN stack.

## Features
- User Authentication (JWT)
- Product Management
- Shopping Cart
- Order Management
- MongoDB Database Integration
- REST API Backend

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## Installation

### Client
npm install
npm start

### Server
npm install
npm run dev
